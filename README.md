# 部活将棋 高校生編

高校の部活動を将棋の駒に見立てて戦う、静的HTML/CSS/JavaScript製のターン制ボードゲームです。

## 公開URL

GitHub Pages: <https://temochiz-lab.github.io/bukatsushogi/>

## 遊び方

GitHub PagesのURLを開くか、ローカルでは `index.html` をブラウザで開くと遊べます。サーバーやビルド手順は不要です。通常URLはPC用レイアウトで表示し、スマートフォン向け表示はURL末尾へ `?mobile=on` を付けます。

- あなたは先手、CPUは後手です。
- 最初に先手の配置と作戦を選びます。学科・部活プリセットのほか、11枠を個別に決める手動編成も使用できます。
- 自分の駒をクリックすると、移動できるマスが表示されます。
- CPUの駒もクリックすると、相手の移動範囲を確認できます。
- 合法手として表示されたマスをクリックすると、自分の駒を動かせます。
- 移動直後は移動元から移動先へ、持ち駒を打った直後は着手マス内に、矢印が約1秒表示されます。
- 開始画面で青い `自動操作` を選ぶと、先手側もCPUになり、CPU同士の対局を観戦できます。
- 対局中は上部の青い `自動操作` / 赤い `手動操作` で、手動操作とCPU同士の自動対局を切り替えられます。
- 捕獲した駒は自軍色で盤面右、CPUに捕獲された駒はCPU色で盤面左に表示されます。
- 開始音はページ起動時ではなく、編成を決定して試合が始まるときに鳴ります。

## 編成

開始時に、先手の編成方法を選べます。

- `自分の配置`: 普通科、工業科、理数科、体育科、商業科、農業科、各部活から先手の初期配置を選びます。部活を選ぶと前列9枚がその部活になります。
- 青い `自動操作`: 選択した先手配置で、CPU同士の自動対局を開始します。
- 赤い `手動操作`: 選択した先手配置で、プレイヤー操作の対局を開始します。
- `編成`: 個別編成画面でも学科・部活を配置のひな型として選択でき、そこから11枠をドラッグまたはクリックで調整できます。空き枠は開始時にランダム補充されます。
- 手動編成は最大3件までブラウザの `localStorage` に保存・読込・削除できます。

## 勝利条件

相手の `生徒会長` を捕獲すると勝利です。

会長以外の駒は、敵陣3段に入る、敵陣3段の中で動く、または敵陣3段から出ると自動で成ります。帰宅部は駒に成マークが付き、その他の部活は通常移動力が+1されます。

- あなたが勝つと `勝利` と表示されます。
- CPUが勝つと `敗北` と表示されます。
- 生徒会長が次に捕獲される状態では、中央に `王手` が約2秒表示されます。
- CPUは強度や作戦にかかわらず、生徒会長を捕獲できる場合はその手を必ず選びます。
- 同じ局面が4回現れると千日手として引き分けになります。
- 決着後は `新規` で新しい対局を始めるか、`棋譜再現` で直前の対局を再生できます。
- 棋譜再現中はCPU強度と残り時間を表示しません。

## 駒

| 駒 | 役割 |
| --- | --- |
| 生徒会長 | 王将相当。捕獲されると敗北。 |
| 帰宅部 | 歩兵相当。前方に1マス進み、敵陣3段で成ると駒に成マークが付く。 |
| 陸上部 | 高機動駒。縦横に長く動け、グラウンドでさらに速い。 |
| 弓道部 | 前方射撃駒。移動は斜め1マス、敵がいる場合だけ前方2マスへ一撃で捕獲する。 |
| 剣道部 | 近接主力。前方と左右に強く、後ろへ下がれない。 |
| 柔道部 | 重盾役。弓道部への防御要素になる。 |
| 水泳部 | 移動盾役。上下左右1マス、プール上では2マス動ける。 |
| ラグビー部 | 通常は前方へ最大2マス、グラウンドでは香車のように前方へ直進する。 |
| 化学部 | 近接役。上下左右1マスを移動し、敵駒がいる場合だけ攻撃する。 |
| 放送部 | 勧誘役。攻撃した会長以外の敵を、その場で味方にする。裏切った駒は元の色のまま向きが反転する。 |
| 新聞部 | 勧誘役。直線移動範囲内で攻撃した会長以外の敵を、その場で味方にする。裏切った駒は元の色のまま向きが反転する。 |
| 美術部 | 近接役。斜め1マスを移動・攻撃する。 |
| 演劇部 | 近接役。周囲1マスを移動・攻撃する。 |
| パソコン部 | 近接役。斜め1マスを移動・攻撃する。 |
| 物理部 | 跳躍役。縦横に1駒飛び越えて動ける。 |
| 吹奏楽部 | 近接役。斜め1マスを移動・攻撃する。 |
| 野球部 | 中距離打撃役。敵がいる場合だけ、縦横2マス先へ一撃で捕獲する。 |
| サッカー部 | 機動役。縦横に最大2マス動ける。 |
| バスケ部 | 跳躍機動役。周囲移動に加えて縦横ジャンプができる。 |
| バレー部 | 近接役。前方3方向と左右1マスを移動し、敵駒がいる場合だけ攻撃する。 |

## 対戦相手

| 対戦相手 | 編成方針 |
| --- | --- |
| ランダム | 対局開始時に学科・部活から1つ抽選する。 |
| 普通科 | 水泳部、化学部、柔道部、剣道部などを使う基本編成。 |
| 工業科 | パソコン部、物理部、化学部などの技術・工作寄り編成。 |
| 理数科 | 化学部、物理部、パソコン部、弓道部などの理系・制御寄り編成。 |
| 体育科 | 陸上部、ラグビー部、野球部、サッカー部、バスケ部などの運動部寄り編成。 |
| 商業科 | パソコン部、放送部、新聞部、美術部などの情報・広報寄り編成。 |
| 農業科 | 化学部、物理部、陸上部、ラグビー部などの理科・体力寄り編成。 |
| 各部活 | 前列9枚の帰宅部が、選択した部活の駒に置き換わる。選択肢には `水泳部`、`野球部` のように部活名だけを表示する。 |

支援・撹乱中心の対戦校編成は、千日手になりやすいため採用していません。

CPU強度は `初級`、`中級`、`上級`、`最上級` の4段階です。初級と中級は速度重視の1手評価、上級と最上級はMinimax探索を使用します。対戦相手は相手編成と評価傾向に反映されます。

自動実行中は、画面上部中央にある強度別の残り時間パネルを直接クリックして、青CPUの強度を対局中に変更できます。強い手の持ち時間は、そのCPUが実際に思考している時間だけを累計し、中級3分、上級2分、最上級2分です。編成中や相手の手番では減りません。初級は無制限です。上級を使い切ると中級へ、中級または最上級を使い切ると初級へ移行します。

赤CPUも同じ時間制ですが、赤CPUの強度はプレイヤーから変更できません。基本は上級を使用し、上級2分を使い切ると中級へ、中級3分を使い切ると初級へ移行します。青・赤とも王手されている間は最上級を使用します。また、会長を動かす手はCPU強度に関係なく最上級扱いで安全性を判定し、次の相手手番で取られない移動先を選びます。安全な移動先がない場合は、会長の合法手からランダムに選びます。

青CPUと赤CPUの初期強度は、どちらも上級です。PC幅では両者の時間パネルを横並びにして、盤面を広く見られるよう上部の高さを抑えています。

青・赤どちらの初級CPUも個別の作戦を無視して全軍突撃し、敵陣方向への前進を優先します。ただし王手されているときは、会長の移動、攻撃駒の捕獲、射線の遮断など、王手を解消する手だけを選びます。中級CPUも王手解消手を優先します。

自分の作戦は編成画面で選択し、青CPUが自動操作するときの手の評価へ反映します。赤CPUは対局開始時に7作戦からランダムに選択します。対局中はCPU強度名の隣に選択・抽選された作戦名を表示し、突撃へ切り替わった場合は `棒銀→突撃` のように追記します。初級では `棒銀→全軍突撃` のように表示します。

| 作戦 | 部活将棋での動き |
| --- | --- |
| 矢倉 | 会長を中央後方に置き、帰宅部・剣道部・柔道部・水泳部を周囲へ集める。 |
| 棒銀 | 陸上部・ラグビー部・サッカー部などの機動駒を攻撃筋へ集め、前進させる。 |
| 四間飛車 | 弓道部・野球部・物理部を四筋付近へ集め、遠隔攻撃を狙う。 |
| 穴熊 | 会長を自陣の角へ寄せ、守備駒で周囲を固める。 |
| 左寄せ | 全軍を盤面左側へ寄せる。 |
| 右寄せ | 全軍を盤面右側へ寄せる。 |
| 突撃 | 準備を行わず、敵陣方向への前進を優先する。 |

矢倉・棒銀・四間飛車・穴熊は、最低4手経過後に配置条件を満たすと完成します。編成や地形の都合で完成しない場合も、自軍が12手指すと準備完了扱いになります。完成後は元の配置へ戻ろうとせず、突撃へ切り替わります。

初級CPUは選択・抽選された作戦を使用せず、最初から全軍突撃を行います。王手を解消できる手がない詰み状態では、ほかの駒による無意味な手より会長自身の着手を優先します。

## 地形

盤面は9x9です。将棋盤らしい黒い罫線で区切り、3x3区画の交点4か所に黒点を表示します。新規対局ごとに地形がランダム生成され、地形によって移動や射線に差があります。地形は中庭を基本に、最大4x2または2x4の施設ブロックがランダムにまとまって配置されます。先手後手の公平性より、毎回違う校内配置を優先しています。各部活は得意フィールドにいると、通常移動力が最大2倍になります。

- グラウンド: 陸上部が動きやすい、開けた地形。
- 校舎: 弓道部の射線を遮ります。
- 体育館: 屋内地形。
- プール: 水泳部が有利。
- 理科室: 化学部と物理部が得意な地形。
- 弓道場: ランダムに現れる部活施設地形。
- 中庭: 標準地形。施設ブロック以外の余白になります。
- 部室棟、テニス: 初期配置側の学校施設地形。

## 効果音

`se/` フォルダのMP3をイベントに割り当てています。

- 開始時: `和太鼓でドドン.mp3`
- 駒を移動・持ち駒を打ったとき: `小パンチ.mp3`
- 駒を取ったとき: `爆発2.mp3`
- 放送部・新聞部が勧誘したとき: `小パンチ.mp3`
- 勝敗が決したとき: `シャキーン1.mp3`

ブラウザの自動再生制限により、開始音は最初のクリック時に鳴る場合があります。

## 実装メモ

- ルール、盤面、駒定義、CPU、UIを分離しています。
- 初級・中級CPUは速度重視の1手評価、上級・最上級CPUはMinimax + alpha-beta pruningです。上級は約4.5秒、最上級は約9秒を探索上限とする反復深化を使用します。
- 上級・最上級の探索中は定期的にブラウザへ制御を返し、表示更新やクリック操作が固まらないようにしています。
- 自動実行中の青CPUは強度を変更できます。赤CPUの強度は表示専用で、プレイヤーから変更できません。
- 駒能力、地形補正、CPU強度、対戦相手ごとの評価重みは `js/config.js` で調整できます。
- 盤面生成は `js/board.js`、初期配置と編成枠は `js/pieces.js`、千日手と王手判定は `js/rules.js` で扱います。
- 成りと持ち駒の再配置は実装済みです。取得した駒を選び、空きマスを選ぶと自軍の駒として打てます。
- CPUは帰宅部以外の持ち駒が5枚以上あると、盤上へ打つ手を積極的に選びます。
- 同じ列に未成の帰宅部がいる場合、その列へ帰宅部を打つ「二帰宅部」は禁止です。
- オンライン対戦は未実装です。
