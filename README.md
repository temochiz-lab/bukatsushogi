# 部活将棋

高校の部活動を将棋の駒に見立てて戦う、静的HTML/CSS/JavaScript製のターン制ボードゲームです。

## 遊び方

`index.html` をブラウザで開くと遊べます。サーバーやビルド手順は不要です。

- あなたは先手、CPUは後手です。
- 自分側は帰宅部と生徒会長以外の駒が、新規対局ごとにランダム編成になります。
- 自分の駒をクリックすると、移動できるマスが表示されます。
- CPUの駒もクリックすると、相手の移動範囲を確認できます。
- 合法手として表示されたマスをクリックすると、自分の駒を動かせます。
- 移動直後は、移動元から移動先へ矢印が約1秒表示されます。
- `観戦モード` を押すと、先手側もCPUになり、CPU同士の対局を観戦できます。

## 勝利条件

相手の `生徒会長` を捕獲すると勝利です。

会長以外の駒は、敵陣3段に入る、敵陣3段の中で動く、または敵陣3段から出ると自動で成ります。帰宅部は成金になり、その他の部活は特殊能力はそのまま通常移動力が+1されます。

- あなたが勝つと `勝利` と表示されます。
- CPUが勝つと `敗北` と表示されます。
- 生徒会長が次に捕獲される状態では、中央に `王手` が約2秒表示されます。

## 駒

| 駒 | 役割 |
| --- | --- |
| 生徒会長 | 王将相当。捕獲されると敗北。 |
| 帰宅部 | 歩兵相当。前方に1マス進み、敵陣3段で成金になる。 |
| 成金 | 帰宅部の成り。前方3方向、左右、後ろ1マスに動ける。 |
| 陸上部 | 高機動駒。縦横に長く動け、グラウンドでさらに速い。 |
| 弓道部 | 前方射撃駒。移動は斜め1マス、射撃は前方2マス。 |
| 剣道部 | 近接主力。前方と左右に強く、後ろへ下がれない。 |
| 柔道部 | 重盾役。弓道部への防御要素になる。 |
| 水泳部 | 移動盾役。上下左右1マス、プール上では2マス動ける。 |
| ラグビー部 | 突撃役。前方向へ強く進む。 |
| 化学部 | 妨害役。上下左右に動き、一時的な立入禁止マスを作る。 |
| 放送部 | 支援役。味方1体の射程や妨害範囲を一時的に伸ばす。 |
| 新聞部 | 偵察役。素早く動き、敵1体を一時的に捕獲不可にする。 |
| 美術部 | デコイ役。隣接マスに囮を置く。 |
| 演劇部 | 撹乱役。隣接する敵の捕獲を一時的に封じる。 |
| パソコン部 | 遠隔妨害役。直線上の敵を一時停止させる。 |
| 物理部 | 跳躍役。縦横に1駒飛び越えて動ける。 |
| 吹奏楽部 | 士気支援役。味方1体に一度だけ捕獲回避を付ける。 |
| 保健委員 | 回復役。隣接味方の状態異常を解除する。 |
| 野球部 | 中距離打撃役。縦横2マス先へ遠隔攻撃できる。 |
| サッカー部 | 機動役。縦横に最大2マス動ける。 |
| バスケ部 | 跳躍機動役。周囲移動に加えて縦横ジャンプができる。 |
| バレー部 | ブロック役。近接移動と味方保護を持つ。 |

## 地形

盤面は9x9です。新規対局ごとに地形がランダム生成され、地形によって移動や射線に差があります。地形は中庭を基本に、2x2、2x3、3x2、最大4x2または2x4の施設ブロックがランダムにまとまって配置されます。先手後手の公平性より、毎回違う校内配置を優先しています。各部活は得意フィールドにいると、通常移動力が最大2倍になります。

- グラウンド: 陸上部が動きやすい、開けた地形。
- 校舎: 弓道部の射線を遮ります。
- 体育館: 屋内地形。
- プール: 水泳部が有利。
- 理科室: 化学部の妨害能力に関わる地形。
- 弓道場: ランダムに現れる部活施設地形。
- 中庭: 標準地形。施設ブロック以外の余白になります。
- 部室棟、テニス: 初期配置側の学校施設地形。

## 効果音

`se/` フォルダのMP3をイベントに割り当てています。

- 開始時: `和太鼓でドドン.mp3`
- 駒を取ったとき: `爆発2.mp3`
- 駒を動かしたとき: `小パンチ.mp3`
- 勝敗が決したとき: `シャキーン1.mp3`

ブラウザの自動再生制限により、開始音は最初のクリック時に鳴る場合があります。

## 実装メモ

- ルール、盤面、駒定義、CPU、UIを分離しています。
- CPUはMinimax + alpha-beta pruningです。
- 駒能力、地形補正、CPU難易度は `js/config.js` で調整できます。
- 成りは実装済みです。持ち駒、オンライン対戦は未実装です。
